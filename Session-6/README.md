# Session 6 - Containerization and Kubernetes Core

Session 6 introduces the runtime foundation required for modern application delivery with containers and Kubernetes.

## Materials

| File | Purpose |
|---|---|
| `Module - 13 & 14.pdf` | Containerization and Kubernetes core concepts. |

## What This Session Achieved

- Explained the problems caused by environment-specific runtime differences.
- Introduced containers as a repeatable packaging and runtime mechanism.
- Built the mental model for images, containers, ports, environment variables, and runtime configuration.
- Introduced Kubernetes as a desired-state platform for running containerized applications.
- Prepared participants for later sessions on Kubernetes resources, Lens, Harbor, and GitOps.

## Key Message

Containers make application runtime more repeatable. Kubernetes then provides the control plane for scheduling, health checking, scaling, and operating those containers.
