# Session 2 - Clean Code, Testing, and CI/CD Automation

Session 2 focuses on the engineering practices that make software easier to maintain, test, and release safely.

## What This Session Achieved

- Explained why clean code matters in financial systems.
- Connected readability, maintainability, simplicity, and testability.
- Introduced test ownership across developers, QA, and platform or DevOps teams.
- Clarified different test types such as unit, component, integration, contract, and E2E tests.
- Discussed the current release flow and why automation reduces manual risk.
- Prepared participants to understand CI/CD as a quality and delivery discipline, not only a toolchain.

## Key Message

Reliable delivery begins before deployment. Clean code, automated tests, and CI/CD gates reduce release risk and make future changes less expensive.
